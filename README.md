# 🌦️ Weather Tracker

A rain, UV index, and lawn care planning dashboard. Displays real-time weather data with hourly breakdowns, ideal outdoor play windows for kids, a mowing day recommender, and an embedded live Doppler radar.

Built as a single-page React app, deployed to Cloudflare Pages.

## Features

- **Current conditions** — Temperature, precipitation, and UV index at a glance
- **14-day navigation** — Browse 7 days back and 6 days forward with per-day hourly detail
- **Hourly timeline** — Temp, rain probability, and UV severity from 6 AM–8 PM
- **Live Doppler radar** — Embedded Windy.com radar (visible on "Today" view only)
- **Ideal Play Windows** — Groups consecutive hours with UV < 4 and no rain
- **Lawn Care Planner** — Scores the next 7 days for mowing based on rain, prior-day rain, and temperature
- **Geolocation** — Optional browser geolocation override; defaults to Chicago, IL

## Security: 14-Day Package Age Gate

All dependencies are pinned to **exact versions** that were published at least **14 days ago**. This mitigates supply chain attacks from freshly-published malicious packages.

### How it works

1. **`.npmrc`** — Forces `save-exact=true` so `npm install <pkg>` never adds `^` or `~` ranges
2. **`overrides`** in `package.json` — Pins transitive dependencies that would otherwise resolve to versions newer than 14 days
3. **`scripts/check-package-age.mjs`** — Audits every package in `package-lock.json` against the npm registry, exits non-zero if any is under 14 days old
4. **`.githooks/pre-commit`** — Runs the age-gate automatically on any commit that touches `package.json` or `package-lock.json`

### Updating dependencies

```bash
# 1. Check what's outdated
npm outdated

# 2. Update versions in package.json (use exact versions only)
#    Verify the publish date is > 14 days ago:
#    npm view <package>@<version> time --json

# 3. Clean install
rm -rf node_modules package-lock.json
npm install

# 4. Run the age gate
npm run audit:age

# 5. If it passes, commit
git add package.json package-lock.json
git commit -m "chore: update dependencies"
```

## Coding Conventions

### General

- **Single-component architecture** — The entire UI lives in `src/App.tsx`. This is intentional for a small dashboard app. If it grows, extract components into `src/components/`.
- **No state management library** — Uses React `useState` and `useEffect` directly. No Redux, Zustand, etc.
- **No router** — Single page, no URL routing needed.

### TypeScript

- **Relaxed strict mode** — `strict: false` in `tsconfig.json` because the original code was generated by Gemini Canvas with implicit `any` types throughout. This is a pragmatic tradeoff.
- **No `@ts-ignore`** — Prefer relaxed tsconfig over scattered suppressions.

### Styling

- **Tailwind CSS 4** — All styling via utility classes in JSX. No separate CSS files beyond the single `@import "tailwindcss"` entrypoint.
- **No custom CSS** — Everything is Tailwind utilities. If you need custom styles, use Tailwind's `@theme` or `@layer` directives in `src/index.css`.

### Dependencies

- **Exact versions only** — No `^` or `~` in `package.json`. The `.npmrc` enforces this automatically.
- **14-day age minimum** — Never add a package published less than 14 days ago. The pre-commit hook enforces this.
- **Minimal deps** — Only add what's truly needed. This app runs on 4 direct dependencies.
